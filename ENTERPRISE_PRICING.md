# Enterprise Pricing Matrix & Licensing Models

**Company:** Krypticsoundz LLC  
**Product:** Kryptic-Agent Embedded Cybernetic Architecture  
**Effective Date:** October 2026  

This document outlines the commercial pricing structures for the Kryptic-Agent real-time active inference control engine. The framework is delivered via a dual-licensing schema to accommodate open-core commercial integrations, heavy industrial automation, and mission-critical defense systems.

---

## 1. Commercial Tier Matrix

### Tier 1: Open-Core (Developer Edition)
*   **Target Audience:** Independent researchers, robotics students, and early-stage prototype developers.
*   **Pricing:** **Free / Open Source** (Under repository license terms).
*   **Inclusions:** Core 1000Hz active inference matrix loop, standard ROS 2 bindings, local SQLite tracking profiles, and public community-driven documentation.
*   **Restrictions:** Strictly non-commercial use; community-based support only; lacks advanced hardware validation suites.

### Tier 2: Pro-Automation (Per-Node Subscription)
*   **Target Audience:** Mid-market commercial drone operators, automated warehouse logistics providers, and industrial assembly plants.
*   **Pricing:** **$250 per Active Node / Month** (Billed annually).
*   **Inclusions:** 
    *   Full production-ready Cyclone DDS transport configurations.
    *    Hard real-time POSIX scheduling wrappers (`-lrt` system utilities).
    *   Asynchronous FastAPI WebSocket analytics monitoring suite.
    *   Next-business-day technical email and repository support.
*   **Volume Discounting:** 15% discount for infrastructure deployments exceeding 50 active nodes.

### Tier 3: Deep-Tech Enterprise (Custom Contract)
*   **Target Audience:** Autonomous vehicle manufacturers, heavy machinery OEMs, and advanced semiconductor factory lines.
*   **Pricing:** **Starts at $45,000 / Year** (Per project or site license).
*   **Inclusions:**
    *   Unlimited local node deployments within the specified project environment.
    *   Custom board support packages (BSP) for specialized ARM or FPGA hardware testbeds.
    *   Dedicated Solution Engineer allocation for initial physical hardware loop tuning.
    *   Guaranteed 4-hour SLA on mission-critical system failures.
